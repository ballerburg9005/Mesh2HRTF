# Ear Acoustic Lab calculation snapshot

Run: ear_20261110_173540_665680

The plotted and tabulated numbers came from the completed NumCalc run. The surface_samples.npz stores boundary geometry and complex boundary pressures at selected solved frequencies, NOT a 3D air volume field. surface_hotspots.csv is human-readable and locates pressure extrema. The full NumCalc workspace is intentionally omitted. The original model STL is optional and not included by default.

This snapshot will become PUBLIC if you push it into a public GitHub fork. To inspect 3D locally, open analysis/surface_3d.html.
